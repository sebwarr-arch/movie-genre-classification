# Movie Genre Classification

## Dataset
Download the MM-IMDb dataset from Kaggle and place the ZIP file in the project folder.

https://www.kaggle.com/datasets/johnarevalo/mmimdb

Rename the ZIP file to `mmimdb.zip`.

The notebook automatically extracts the required files:
- `multimodal_imdb.hdf5`
- `metadata.npy`

This file is 13gb, so make sure space is not an issue on your computer

## Running the Notebook
1. Install the required packages using `pip install -r requirements.txt`.
2. Open `movie_genre_classification.ipynb` in Jupyter Notebook.
3. Run the notebook cells in order.

Extracted dataset files and cached results are generated locally and are not included in the repository.
